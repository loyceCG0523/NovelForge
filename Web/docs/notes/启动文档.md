## 推荐：一键启动与监控

双击项目根目录的 `启动NovelForge.cmd`。浏览器会打开本地控制台：

```
http://127.0.0.1:3900
```

控制台可以一键启动、重启或停止前端、API、Agent Worker 和 Memory Worker，并实时查看逐步骤进度、服务状态、Redis 队列长度及各进程日志。关闭浏览器不会停止服务；需要停服时在控制台点击“全部停止”。

一键启动脚本会先执行 Docker Compose，自动拉起 PostgreSQL、Redis 和 MinIO。若 Docker Desktop 尚未运行，请先启动 Docker Desktop。

```powershell
docker compose up -d
```

## 手动启动

**1. 启动基础服务**
在 PowerShell 里执行：

```
cd D:\CodeProject\AgentProject\NovelForge\Web
docker compose up -d
docker compose ps
```

确认 `postgres`、`redis`、`minio` 都是 `healthy` 或 `Up`。

**2. 启动后端 API**
新开一个 PowerShell：

```
cd D:\CodeProject\AgentProject\NovelForge\Web\apps\api
conda activate novelforge-api
uvicorn app.main:app --reload --host 127.0.0.1 --port 8100
```

后端地址：

```
http://127.0.0.1:8100
```

**3. 启动两个 Worker**
分别打开两个 PowerShell：

```
cd D:\CodeProject\AgentProject\NovelForge\Web\apps\worker
conda activate novelforge-api
python -m worker.main --queue agent
```

```
cd D:\CodeProject\AgentProject\NovelForge\Web\apps\worker
conda activate novelforge-api
python -m worker.main --queue memory
```

Agent Worker 负责正文生成、审校与定向修改，Memory Worker 负责结构化记忆和时间线同步。

**4. 启动前端**
再新开一个 PowerShell：

```
cd D:\CodeProject\AgentProject\NovelForge\Web\apps\web
conda activate novelforge-api
npm run dev
```

前端地址：

```
http://127.0.0.1:3000
```
