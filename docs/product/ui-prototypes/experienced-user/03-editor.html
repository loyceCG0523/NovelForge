第二十四章 夜入军府

雨停以后，军府后巷只剩下檐角滴水的声音。

林澈把斗笠压低，沿着墙根走到第三盏灯下。那里的青砖比别处新，缝隙里还残着湿泥，像是刚被人撬开又匆忙按了回去。

沈微跟在他身后，左手一直按着肋下。她没有喊疼，只在转身时停了半息。

“你还能走？”林澈问。

“不能走的话，”她抬眼看了看墙上的巡夜影子，“你背我进去？”

林澈没接话。他蹲下身，指腹从砖缝里抹出一点黑灰。灰里混着细碎铜屑，颜色很旧，和他在祠堂地下见过的那枚铃舌一模一样。

墙内忽然传来一声极轻的铃响。

不是风声。也不是巡夜人的铜牌。

他知道，自己已经没有退路了。
