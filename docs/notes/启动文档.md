**1. 启动基础服务**
在 PowerShell 里执行：

```
cd D:\CodeProject\AgentProject\NovelForge
docker compose up -d
docker compose ps
```

确认 `postgres`、`redis`、`minio` 都是 `healthy` 或 `Up`。

**2. 启动后端 API**
新开一个 PowerShell：

```
cd D:\CodeProject\AgentProject\NovelForge\apps\api
conda activate novelforge-api
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

后端地址：

```
http://127.0.0.1:8000
```

**3. 启动 Worker**
再新开一个 PowerShell：

```
cd D:\CodeProject\AgentProject\NovelForge\apps\worker
conda activate novelforge-api
python -m worker.main
```

Worker 负责消费章节生成、样本分析、作品圣经、剧情事件等异步任务。

**4. 启动前端**
再新开一个 PowerShell：

```
cd D:\CodeProject\AgentProject\NovelForge\apps\web
conda activate novelforge-api
npm run dev
```

前端地址：

```
http://127.0.0.1:3000
```
